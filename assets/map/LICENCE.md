# Map sources

`places.topojson` is written by `tools/build-map-geometry.ts` from:

- Country outlines: [world-atlas](https://github.com/topojson/world-atlas) `countries-50m.json` (ISC licence), which is [Natural Earth](https://www.naturalearthdata.com/) 1:50m data (public domain).
- US state and Canadian province and territory outlines: Natural Earth 1:50m `admin_1_states_provinces`, version 5.1.2 (public domain).
